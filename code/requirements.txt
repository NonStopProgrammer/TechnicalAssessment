# ---------------------------------------------------------------------------
# MVP / local-dev dependency set.
#
# Everything here is lightweight (pure Python or small compiled wheels) and
# installs without a GPU, without downloading multi-GB model weights, and
# without a paid API key. This is deliberate: it is what lets
# `pip install -r requirements.txt` produce a stack that actually runs
# end-to-end (backend + rag + agentic + mcp + eval) using the local_stub /
# local_hash / lexical provider paths described in `.env.example`.
#
# The *production* providers referenced throughout the architecture
# (vLLM, HuggingFace TEI, LLMLingua, Presidio, NeMo Guardrails, RAGAS'
# heavier extras, Apache Airflow) are declared in `requirements-full.txt`
# instead — see that file's header for why they're split out.
# ---------------------------------------------------------------------------
